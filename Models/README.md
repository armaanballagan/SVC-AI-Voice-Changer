# Voice models

The model weights are too large for git. Download them from the
[v1.0 release](https://github.com/armaanballagan/SVC-AI-Voice-Changer/releases/tag/v1.0)
and unzip each one into a folder named after the voice. Use spaces, not
underscores (`Hatsune_Miku.zip` goes in `Models/Hatsune Miku/`), so you end up with:

```
Models/
  Armaan/
    model.pth
    config.json
  Dio/
    model.pth
    config.json
  ...
```

The folder name is the speaker name shown in the GUI's speaker menu.
